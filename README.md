# 瞬間英作文ドリル（QQ English 用）

iPhone Safari 向けの瞬間英作文トレーニングアプリ。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `standalone.html` | ホーム画面追加（PWA）用のページ。これを開く |
| `page.html` | claude.ai のアーティファクト公開用ページ |
| `styles.css` | スタイル（ライト／ダーク両対応） |
| `app.js` | アプリ本体。第3回・第4回の2セット（各 基本10問＋類似10問）を同梱 |
| `sets.json` | 収録セットの正本。`app.js` の該当部分はここから生成する |
| `cheer/` | 応援スタンプ。正答数の帯ごと（low 4枚 / mid 3枚 / high 3枚） |
| `manifest.json` / `sw.js` / `icon-*.png` / `apple-touch-icon.png` | PWA・オフライン用（`icon.svg` は旧アイコン・未使用） |

## 使い方

HTTPS で配信されるフォルダに丸ごと置き、`standalone.html` を Safari で開いて
「ホーム画面に追加」する。学習データは端末の localStorage に保存される。

## 学習システム

1. **STEP 1 基本文 10問** — 日本語を見て3秒以内に声に出す → 「正解を見る」→ 自己採点
2. 10問すべてに正解判定が付くと **STEP 2 類似問題 10問** が解放される
3. 再挑戦では未正解の問題だけが出題される（誤答が多い順）
4. 3回以上間違えた文は「重点復習」として表示される

## レッスンセットの追加

「追加」タブに JSON を貼り付ける。`id` が同じセットは重複登録されない。

```json
{
  "id": "qq-2026-11-27",
  "date": "2026-11-27",
  "teacher": "講師名",
  "title": "第5回 ふりかえり",
  "basic":   [{ "ja": "…", "en": "…", "alt": ["…"], "note": "…" }],
  "similar": [{ "ja": "…", "en": "…", "alt": ["…"], "note": "…" }]
}
```
